🖱️ Mouse Events

click
Fires when an element is pressed and released.
Click button to test
JavaScript Example 
document.getElementById("myButton").addEventListener("click", function(e) {
    document.getElementById("myParagraph").textContent = "Button clicked!";
    document.getElementById("myParagraph").style.color = "red";
});
dblclick
Fires when an element is double-clicked rapidly.
Double-click button
JavaScript Example 
element.addEventListener("dblclick", function(e) {
    console.log("Element double-clicked!");
});
mousedown / mouseup
Fires as soon as a mouse button is pressed down or released.
Press and hold mouse button
JavaScript Example 
element.addEventListener("mousedown", function() {
    // Mouse button held down
});
element.addEventListener("mouseup", function() {
    // Mouse button released
});
mouseenter / mouseleave
Fires when cursor enters/leaves element boundary (no bubbling).
Hover Cursor Here
Hover over container
JavaScript Example 
element.addEventListener("mouseenter", function() {
    document.getElementById("status").textContent = "Mouse entered!";
});
element.addEventListener("mouseleave", function() {
    document.getElementById("status").textContent = "Mouse left!";
});
mouseover / mouseout
Fires when hovering over an element OR its children (bubbles).
Hey I am Kubra
JavaScript Example 
document.getElementById("myButton").addEventListener("mouseover", function() {
    document.getElementById("onmouseover").textContent = "Mouse is over the button!";
}); 
document.getElementById("myButton").addEventListener("mouseout", function() {
    document.getElementById("onmouseover").textContent = "Mouse is out of the button!";
});
mousemove
Fires continuously as the mouse moves over an element.
Move mouse cursor in this box
X: 0px, Y: 0px
JavaScript Example 
element.addEventListener("mousemove", function(e) {
    console.log(`X: ${e.clientX}, Y: ${e.clientY}`);
});
contextmenu
Fires when right-clicking. Can be prevented with e.preventDefault().
Right-Click Inside Box
Right click to trigger custom handler
JavaScript Example 
element.addEventListener("contextmenu", function(e) {
    e.preventDefault(); // Prevents default context menu
    console.log("Custom context menu action");
});

⌨️ Keyboard Events

keydown / keyup
Fires when a key is pressed down or released (must be on focusable element).
Press key inside input...
JavaScript Example 
// Note: Keyboard events require focusable elements (like <input> or window)
document.getElementById("myInput").addEventListener("keydown", function(e) {
    document.getElementById("output").textContent = `Key pressed: ${e.key}`;
});

document.getElementById("myInput").addEventListener("keyup", function(e) {
    console.log(`Key released: ${e.key}`);
});

📝 Form & Input Events

input
Fires immediately whenever value changes in an <input> or <textarea>.
Live text output target
JavaScript Example 
document.getElementById("myInput").addEventListener("input", function(e) {
    document.getElementById("myParagraph").textContent = e.target.value;
    document.getElementById("myParagraph").style.fontSize = "24px";
});
change
Fires when element value is committed (e.g. selection changed or focus lost).
Select an option
JavaScript Example 
selectElement.addEventListener("change", function(e) {
    console.log("Selected value:", e.target.value);
});
focus / blur
focus fires when element gains active focus; blur fires when focus is lost.
Focus status indicator
JavaScript Example 
inputElement.addEventListener("focus", function() {
    console.log("Input has focus");
});
inputElement.addEventListener("blur", function() {
    console.log("Input lost focus");
});
submit / reset
Fires when a <form> is submitted or reset. Use e.preventDefault() to handle via JS.
Form action log
JavaScript Example 
formElement.addEventListener("submit", function(e) {
    e.preventDefault(); // Prevent page refresh
    console.log("Form submitted!");
});
select
Fires when user highlights/selects text inside an input field.
Select text inside input
JavaScript Example 
inputElement.addEventListener("select", function(e) {
    console.log("Text highlighted by user");
});

📋 Clipboard Events

copy / cut / paste
Fires when content is copied, cut, or pasted into an element.
Clipboard event detector
JavaScript Example 
element.addEventListener("copy", function() {
    console.log("Content copied!");
});
element.addEventListener("paste", function(e) {
    let pastedText = e.clipboardData.getData("text");
    console.log("Pasted:", pastedText);
});

📦 Drag & Drop Events

dragstart / dragover / drop
Native HTML5 drag and drop events between elements.
Drag Me
Drop Item Here
Drag box into target area
JavaScript Example 
// Make element draggable in HTML: <div draggable="true">
dragItem.addEventListener("dragstart", function(e) {
    e.dataTransfer.setData("text/plain", "Sample Data");
});

dropTarget.addEventListener("dragover", function(e) {
    e.preventDefault(); // Required to allow dropping
});

dropTarget.addEventListener("drop", function(e) {
    e.preventDefault();
    let data = e.dataTransfer.getData("text/plain");
});

🖥️ Window & Page Load Events

DOMContentLoaded & load
DOMContentLoaded fires when DOM HTML is ready. load fires when images & stylesheets finish.
Resource load status
JavaScript Example 
// Note: 'load' fires on window or resources (<img>), NOT standard buttons
window.addEventListener("DOMContentLoaded", function() {
    console.log("DOM tree built!");
});

window.addEventListener("load", function() {
    document.getElementById("onload").textContent = "Page fully loaded!";
});
resize
Fires on window when browser window dimensions change.
Resize Browser Window
Resize window to see viewport width x height
JavaScript Example 
window.addEventListener("resize", function() {
    console.log(`Width: ${window.innerWidth}, Height: ${window.innerHeight}`);
});
scroll
Fires when an element or the window is scrolled.
Line 1: Scroll inside this box...
Line 2: Keeping scrolling down...
Line 3: Event triggers on scroll.
Line 4: Scroll distance increases.
Line 5: Bottom reached!
Scroll inside box
JavaScript Example 
element.addEventListener("scroll", function(e) {
    console.log("Scrolled position:", element.scrollTop);
});
